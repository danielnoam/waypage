### Changed
- Story page is now called Website sync. Link a collection to a site's
  contents page, or paste any of its chapters and it finds the contents
  page from there.
- Website sync reads chapter lists from many more sites, not only the
  ones Waypage knows (Royal Road, AO3 and the rest): lists split into
  volumes or arcs, lists where each chapter sits in a box of its own,
  lists spread over several pages, and chapters with names but no
  numbers.
