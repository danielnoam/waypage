### Added
- GitHub sync has a Notes switch above Feeds in What this device syncs. With it on, each note goes up whole (its sheets, what is drawn and typed on them, pictures put on it and the PDF it was made from, up to 50 MB) and comes down on your other devices. A note written on two devices keeps the copy saved last. With it off, notes are left as they are here and on GitHub.
- Google Drive has a Notes switch above Feeds in What goes in. With it on, each note goes to Drive as a PDF in a Notes folder at each backup, sent again only when the note changed, and removed when you delete the note. It can only be turned on while Notes is on in GitHub sync, and goes off with it. Notes still aren't in the backup file; they come back through GitHub sync.
- Tapping Drive's greyed-out Notes switch says to turn on Notes in GitHub sync first.

### Changed
- Notes are no longer only on this device.
