### Added
- Edit clips now edits files read from where they are, too: EPUB, Kindle, FB2, Markdown, text, HTML and email. Pick All files, a collection, or files picked in the library. Only Waypage's copy of the words changes; the file itself stays as it is, and the change stays on that device. PDFs and comics aren't offered: a PDF shows its printed pages, and a comic has no words.
