### Added
- Add a folder, on the Add page: every book, note and comic in the folder you pick (and its folders) is added on its own, in a collection named after its folder, and its sound files become one audiobook. In the app each file is read from where it is; in a browser the files are copied in and sound files are left out.

### Changed
- The Add page's options are now Add a file, Add a folder and New note. Add a folder replaces Open an audiobook folder.
